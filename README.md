# Sri Lanka Hospital Bed Resource Allocation Analysis

## Project Overview

This Power BI project analyzes hospital bed distribution across Sri Lanka's 25 districts using 2024 population and hospital bed data. The aim is to identify potential healthcare resource gaps and support data-driven resource allocation decisions.

## Business Scenario

Public Health – Healthcare Resource Planning

## Stakeholder

Planning Officer, Ministry of Health, Sri Lanka.

## Decision Question

Which districts in Sri Lanka should receive priority for hospital bed resource allocation based on population size and hospital bed availability?

## Project Objectives

- Analyze population distribution across districts.
- Compare hospital bed capacity across districts.
- Calculate hospital beds per 1,000 people.
- Identify districts with relatively low hospital bed capacity.
- Develop an interactive Power BI dashboard.

## Data Sources

- Department of Census and Statistics, Sri Lanka – Census of Population and Housing 2024.
- Ministry of Health, Sri Lanka – Annual Health Bulletin 2024.

## Tools and Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- GitHub

## Key Performance Indicators

- Total Population
- Total Hospital Beds
- Hospital Beds per 1,000 People
- Total Districts

## Expected Outcome

An interactive dashboard that supports healthcare planning by highlighting differences in hospital bed capacity relative to population across Sri Lanka.

## Limitations

Hospital bed capacity does not represent currently vacant beds. Additional healthcare indicators are required to determine actual resource needs.
